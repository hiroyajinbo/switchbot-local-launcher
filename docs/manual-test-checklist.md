# 手動テストチェックリスト

## 起動

- [ ] `.env` と `config.json` を作成した状態で `python -m app` で起動できる
- [ ] `http://127.0.0.1:8765` をブラウザで開ける
- [ ] `.env` 未設定時に分かりやすいエラーが表示される

## 操作

- [ ] 設定ファイルに定義したボタンが表示される
- [ ] device commandのボタンで実機が動作する
- [ ] sceneのボタンでシーンが実行される
- [ ] 成功時に画面へ成功メッセージと時刻が表示される

## エラー

- [ ] 存在しないdevice_idでエラーが表示される
- [ ] 存在しないscene_idでエラーが表示される
- [ ] ネットワーク不通時にアプリが落ちない
- [ ] 未定義のボタンIDをAPIに送った場合に404が返る
